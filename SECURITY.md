# Security policy

Please report security issues through [GitHub private vulnerability reporting](https://github.com/SovMart-Team/Codeception-Module-Joomla/security/advisories/new) instead of opening a public issue. Include the affected version, a minimal reproduction, and the expected impact.

Never include production credentials, Joomla session values, fixture passwords, API tokens, or authorization headers in a report. Use disposable test values.
